# HU-003: Consulta y almacenamiento en caché de datos del medidor

## Historia de usuario

Como técnico, quiero consultar y visualizar los datos del medidor enviados por el sistema de la oficina, para acceder a su información y evitar esperar una nueva descarga al consultar el mismo medidor durante la jornada.

## Criterios de aceptación

- **CA-01:** Con señal, la aplicación debe consultar el sistema de la oficina y mostrar los datos del medidor.
- **CA-02:** La aplicación debe mostrar la dirección, sector, número de cuenta, estado, última lectura con su fecha y consumo promedio mensual.
- **CA-03:** La aplicación debe guardar en caché los datos consultados del medidor.
- **CA-04:** Si el técnico vuelve a consultar el mismo medidor durante la jornada, la aplicación no debe esperar una nueva descarga.
