# HU-010: Corrección y validación de registros de lecturas

## Historia de usuario

Como técnico, quiero corregir una lectura mientras no se haya enviado y evitar registrar dos veces el mismo medidor en el mismo mes.

## Criterios de aceptación

- **CA-01:** El técnico puede corregir una lectura mientras no se haya enviado.
- **CA-02:** Una vez enviada la lectura, el técnico ya no puede corregirla.
- **CA-03:** La aplicación no debe permitir registrar dos veces el mismo medidor en el mismo mes.
