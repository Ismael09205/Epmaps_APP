# HU-004: Registro de lectura sin conexión

## Historia de usuario

Como técnico, quiero registrar la lectura del medidor sin señal, para que quede pendiente de verificar y se compare con la lectura anterior cuando se recupere la conexión.

## Criterios de aceptación

- **CA-01:** La aplicación debe permitir al técnico registrar la lectura sin señal.
- **CA-02:** La lectura registrada sin señal debe quedar marcada como pendiente de verificar.
- **CA-03:** Cuando se recupere la conexión, la aplicación debe comparar la lectura registrada con la anterior.
