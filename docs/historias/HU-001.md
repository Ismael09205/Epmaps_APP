# HU-001: Identificación del técnico

## Historia de usuario

Como técnico, quiero identificarme en la aplicación mediante mi código de empleado y una clave, para mantener mi sesión iniciada hasta que cierre sesión.

## Criterios de aceptación

- **CA-01:** La aplicación debe permitir al técnico identificarse mediante su código de empleado y una clave.
- **CA-02:** La aplicación debe mantener la sesión del técnico iniciada hasta que cierre sesión.
- **CA-03:** Los datos de usuario pueden estar quemados; no es necesario implementar la gestión de usuarios.
