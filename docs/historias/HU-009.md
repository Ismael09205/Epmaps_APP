# HU-009: Envío automático de lecturas y estado de conexión

## Historia de usuario

Como técnico, quiero que las lecturas se envíen automáticamente cuando haya conexión y visualizar el estado de conexión y la cantidad de lecturas pendientes de envío, para conocer el estado de los envíos.

## Criterios de aceptación

- **CA-01:** Las lecturas deben enviarse automáticamente cuando haya conexión.
- **CA-02:** Las lecturas no deben duplicarse aunque la señal se corte en medio de un envío.
- **CA-03:** En todas las pantallas, la aplicación debe mostrar al técnico si tiene conexión.
- **CA-04:** Debe generarse un cuadro informativo en donde la aplicación muestre cuántas lecturas le quedan por enviar.
