# HU-008: Continuación o descarte de un registro pendiente

## Historia de usuario

Como técnico, quiero continuar la captura pendiente o descartarla si la aplicación se cierra a mitad del proceso de registro, para retomar o descartar el registro al abrirla de nuevo.

## Criterios de aceptación

- **CA-01:** Si la aplicación se cierra a mitad de un proceso de registro, al abrirla de nuevo debe ofrecer continuar la captura pendiente o descartarla.
