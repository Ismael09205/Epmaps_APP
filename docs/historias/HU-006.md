# HU-006: Validación de consumo y evidencia fotográfica

## Historia de usuario

Como técnico, quiero comparar la lectura actual con la anterior para calcular el consumo del mes y detectar consumos elevados.

## Criterios de aceptación

- **CA-01:** La aplicación debe comparar la lectura actual con la anterior para calcular el consumo del mes.
- **CA-02:** Si el consumo supera el triple del promedio mensual del medidor, la aplicación debe emitir una advertencia.
- **CA-03:** Cuando se supere el triple del promedio mensual, el técnico debe confirmar que revisó el medidor de agua.
- **CA-04:** Cuando se supere el triple del promedio mensual, la foto del medidor debe ser obligatoria.
